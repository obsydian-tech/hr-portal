Lock: acceptance-lock/be-18

Nothing here opens the app. All five tests run once, in `desktop-1280`.

- **AC-1** reads `infra/*.tf` as text: recordConsent is off `allowed_role_arns`, nothing else leaves a list,
  and the key policy module matches the snapshot.
- **AC-2** checks consent reads. It runs the start page and consent handlers against a consents table whose
  reads miss unless they are consistent.
- **AC-3** checks token types. It calls the real `isIdToken`, then refuses a non-ID token on the start page,
  consent, the three owner routes and three HR routes.
- **AC-4** checks errors. It fails every DynamoDB call with a message holding a marker and an address. The
  marker and address must appear in no log line and no answer, and the error name is logged as `errorName`.
- **AC-5** checks email case. It runs the post sign-in trigger with mixed-case emails, then
  `scripts/onboarding/lowercase-emails.mjs` (`main(['--plan'])` and `main(['--apply'])`) against a fake
  employees table.

AC-6 needs no new test. It is ONB-05's AC-11 on pepla-dev after the apply.

The script must export `async function main(args)`, returning `{ exitCode }`, and must not run by itself
when imported.

No words are new. Every refusal uses the route's existing text.
